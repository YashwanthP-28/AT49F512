# AT49F512 Interactive Hardware Lab

An interactive, browser-based learning lab for the **Atmel AT49F512** 512Kbit / 64Kbyte 5V parallel Flash memory.

This project teaches the AT49F512 from the ground up:

```text
Silicon / memory cell
→ memory array
→ address decoder
→ data path
→ control logic
→ parallel bus
→ read/write/erase commands
→ programmer hardware concept
→ binary dump
→ hex editing
→ programming
→ verification
