Important size distinction

512Kbit524,288 bits
64Kbyte65,536 bytes
64K × 865,536 byte locations, each 8 bits wide

The datasheet says: “Its 512K of memory is organized as 65,536 words by 8 bits.” [DATASHEET]

Do not confuse 512Kbit with 512Kbyte. This chip is 64Kbyte, not 512Kbyte.

Key datasheet features

  • 5V read, 5V reprogramming [DATASHEET]
  • Fast read access time: 55 ns for -55 parts [DATASHEET]
  • Internal program control and timer [DATASHEET]
  • 8K byte boot block with lockout [DATASHEET]
  • Fast erase cycle time: 10 seconds [DATASHEET]
  • Byte-by-byte programming: 10 µs/byte typical [DATASHEET]
  • DATA polling for end of program detection [DATASHEET]
  • Typical 10,000 write cycles [DATASHEET]

Read operation

READ:
CE = LOW
OE = LOW
WE = HIGH

Selected address appears on A0-A15.
Flash drives I/O0-I/O7 with stored byte. [DATASHEET]

Outputs are high impedance whenever CE or OE is high. [DATASHEET]

Program/erase model

Erased state = logical 1, usually 0xFF. [DATASHEET]
Programming changes bits toward 0. [DATASHEET]
A programmed 0 cannot be programmed back to 1. [DATASHEET]
Only erase can convert 0s back to 1s. [DATASHEET]

The interactive Bit Rule Checker tab lets you test whether a byte change can be done without erase.

  • PLCC package drawing also references a pin no. 1 identifier. [DATASHEET]
  • Look for a dot, bevel, cut corner, or molded identifier. [ENGINEERING KNOWLEDGE]
  • Never assume orientation from memory alone. [DESIGN RECOMMENDATION]

PLCC caution

The supplied datasheet text includes a PLCC diagram, but the extracted text is not as clean as the TSOP/VSOP table. For a physical PLCC part, confirm pin 1 and pin assignment from a clear photo and the original datasheet drawing before wiring.

Incorrect pinout can damage the chip.

Parallel bus architecture

              ADDRESS BUS
Controller ─────────────────→ A0-A15
Controller ←────────────────→ I/O0-I/O7
Controller ─────────────────→ CE
Controller ─────────────────→ OE
Controller ─────────────────→ WE

The address bus selects one byte location. The bidirectional I/O bus carries the byte. The controller drives the bus during command/program writes. The Flash drives the bus during reads.

WE-controlled program waveform concept

ADDRESS  =====< valid address >=====================
CE       ____________________________________________
OE       --------------------------------------------
DATA     ========< valid data >======================
WE       ---------___________-----------------------
                  ^         ^
                  |         |
                  |         Data latched on rising edge
                  Address latched on falling edge

The datasheet says addresses are latched on the falling edge of WE or CE, whichever occurs last, and data is latched on the rising edge of WE or CE, whichever occurs first. [DATASHEET]

DATA polling

  • Uses I/O7. [DATASHEET]
  • During programming, attempted read of last byte loaded gives complement on I/O7. [DATASHEET]
  • After completion, true data is valid. [DATASHEET]
Programming 0x42:
0x42 = 01000010
I/O7 true value = 0
During programming, I/O7 complement = 1
After completion, I/O7 = 0

Toggle bit

  • Uses I/O6. [DATASHEET]
  • I/O6 toggles during program or erase. [DATASHEET]
  • When operation completes, I/O6 stops toggling and valid data is read. [DATASHEET]
  • Any address may be used, but the address should not vary. [DATASHEET]
Read 1: I/O6 = 0
Read 2: I/O6 = 1
Read 3: I/O6 = 0
Read 4: I/O6 = 1
Read 5: I/O6 = stable → complete

Hardware data protection

  • VCC sense: if VCC is below 3.8V typical, program is inhibited. [DATASHEET]
  • Program inhibit: OE low, CE high, or WE high inhibits program cycles. [DATASHEET]
  • Noise filter: pulses less than 15 ns typical on WE or CE will not initiate a program cycle. [DATASHEET]

Absolute maximum ratings

All input voltages, including NC pins-0.6V to +6.25V [DATASHEET]
All output voltages-0.6V to VCC + 0.6V [DATASHEET]
Voltage on OE-0.6V to +13.5V [DATASHEET]
Storage temperature-65°C to +150°C [DATASHEET]

Absolute maximum ratings are stress ratings only. Do not design to them. [DATASHEET]
